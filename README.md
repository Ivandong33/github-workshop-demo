# GitHub 实战操作演示

这个仓库用于演示 GitHub 的核心功能。

## 功能演示

- ✅ 仓库创建与 README 初始化
- ✅ 分支管理与 Pull Request
- ✅ GitHub Actions CI/CD
- ✅ GitHub Pages 静态站部署
- ✅ Issues 与 Project 看板

## 快速开始

```bash
git clone https://github.com/Ivandong33/github-workshop-demo.git
cd github-workshop-demo
```
